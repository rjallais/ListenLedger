* Overview
MonthlyListeners is a small Go CLI that reads a list of Spotify artist IDs from =input.txt=, fetches each artist’s “monthly listeners” count, and writes the results into =artist_stats.json=.

It optimizes for throughput and cost by intelligently splitting the workload between two providers:
- **Browserless** (using Headless Chrome/BQL)
- **ScrapingAnt** (using HTML scraping)

By default, if both providers are configured, it splits the work: even-indexed artist IDs go to Browserless, and odd-indexed IDs go to ScrapingAnt, effectively doubling the concurrency limit of free-tier plans.

* How It Works
- **Input**: One Spotify artist ID per line in =input.txt=. Empty lines are ignored.
- **Fetch Strategy**:
  - **Dual Provider Mode**: If both =BROWSERLESS_TOKEN= and =SCRAPINGANT_TOKEN= are set, the application launches two concurrent workers. One worker processes even indices using Browserless, and the other processes odd indices using ScrapingAnt.
  - **Single Provider Mode**: If only one token is provided, it uses that provider for all requests.
  - **Fallback**: Within each provider's logic, retries are handled with exponential backoff.
- **Parse**: The program extracts the listener count (e.g., "1,234,567") from the provider's response.
- **Store**: Results are merged into =artist_stats.json=. Existing entries are updated; new ones are added.
- **Reliability**: Each fetch retries up to 2 times (configurable) with backoff.

* Repo Layout
- =main.go=: program entry point
- =config/=: configuration management
- =internal/fetcher/=: orchestration logic (concurrency, retries)
- =internal/spotify/=: client implementation for Browserless and ScrapingAnt
- =internal/storage/=: file I/O for input and output
- =go.mod=: module config
- =input.txt=: sample list of artist IDs

* Prerequisites
- **Go toolchain** with support for the =jsonv2= experiment.
  - Build/run using: =GOEXPERIMENT=jsonv2=.
- **Provider Tokens**:
  - =BROWSERLESS_TOKEN= (Required for Browserless)
  - =SCRAPINGANT_TOKEN= (Required for ScrapingAnt)

* Configuration
Set your API tokens in =mise.toml= under the =[env]= section (or export them in your shell):

#+begin_src toml
[env]
PROJECT_NAME = "MonthlyListeners"
BROWSERLESS_TOKEN = "your_browserless_token"
SCRAPINGANT_TOKEN = "your_scrapingant_token"
# Optional overrides
MAX_CONCURRENCY = "1" # per provider
MAX_RETRIES = "2"
#+end_src

* Build & Run

#+begin_src sh
# Build
GOEXPERIMENT=jsonv2 go build -o MonthlyListeners .

# Run
GOEXPERIMENT=jsonv2 ./MonthlyListeners
#+end_src

Using =mise=:
#+begin_src sh
mise run build
mise run run
#+end_src

* Troubleshooting
- **401/403 Errors**: Check your API tokens.
- **Provider Logs**: successful fetches are logged with the provider name:
  - =provider=scrapingant artist=... listeners=...=
  - =provider=browserless artist=... listeners=...=


* Caveats & Ethics
- **Token security**: Do not commit real tokens. Treat them as secrets and rotate if exposed.
- **Website terms**: Ensure your usage complies with Spotify’s and Browserless’s terms of service. Be considerate with concurrency and request volume.
- **Fragile selectors**: UI changes can break scraper logic; plan to maintain the selector and extraction code over time.
